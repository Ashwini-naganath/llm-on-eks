# DevOps-AI: Deploying an Open-Source LLM on Amazon EKS

## Project Overview

This project demonstrates how to deploy an open-source Large Language Model (LLM) on an Amazon EKS cluster using modern DevOps practices. It covers the complete lifecycle—from local development and containerization to infrastructure provisioning with Terraform, Kubernetes deployment, CI/CD automation, and monitoring with Prometheus and Grafana.

The goal of this project is to build a production-style AI application while gaining practical experience in DevOps, cloud infrastructure, and MLOps concepts.
